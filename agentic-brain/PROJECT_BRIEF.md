# Project Brief

Project Name:
ITMB AI Knowledge Bot

Goal:
Create an AI-powered company assistant capable of answering questions about ITMB services, pricing, products and internal knowledge.

MVP Features:

* Company knowledge base
* Retrieval layer
* AI response generation
* Session memory
* Simple web interface

Success Criteria:

* User can ask questions
* Answers are grounded in company documents
* Conversation context is preserved
* Project is documented and reproducible
